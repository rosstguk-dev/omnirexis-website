# Omnirexis — minimum delivery kit

**Owner:** Chief of Staff (client delivery & customer success)  
**Locked:** 18 Sep 2026  
**Purpose:** Fulfil what Sales sold without reinventing the job or burning founder time.

## 1. Product truth (do not oversell)

| Offer | What we deliver | What we do **not** promise |
|---|---|---|
| Strategy call → scoped implementation | Agreed automation / voice / growth work from the Zoom | Fixed price before scoping; PT platform as live |
| Rapid studio | Fixed packages on /rapid-services (Content Sprint, Ops Doc Sprint, etc.) | Unlimited revisions; custom builds under Rapid price |
| Leisure systems | Conversation + discovery for club ops | Instant software install from first email |
| PT platform | Interest capture only (`/contact?intent=pt-*`) | Live product sale |

Price for scoped work stays with Ross until a written playbook says otherwise.

## 2. Sales → delivery handover (required on booked Zoom / hot lead)

Sales notes in HubSpot deal or CoS chat:

1. **Problem** the customer named (in their words).
2. **Deliverable shape** (Rapid SKU **or** scoped implementation outline).
3. **Rough commercial path** (Rapid checkout / quote after call / retain later).
4. **Anything refused** (so we do not quietly expand scope).

If the note is missing, CoS asks Sales once before kickoff — never invent scope.

## 3. Kickoff checklist (every paid close)

- [ ] Confirm primary contact + billing email
- [ ] Confirm what was sold matches the table above
- [ ] Kickoff date + channel (email / Zoom)
- [ ] Access needed (inboxes, CRM, website, tools)
- [ ] Success definition in one sentence (customer outcome)
- [ ] HubSpot deal = Closed Won; n8n onboarding alert acknowledged
- [ ] Owner after kickoff: CoS / Client Delivery (not “whoever remembers”)

## 4. Rapid fulfilment (repeatable)

1. Confirm package + payment.
2. Collect inputs (brief form — keep to one page).
3. Deliver within the stated package scope.
4. One revision pass unless package says otherwise.
5. Close ticket; ask for a short outcome note (retention / referral).

## 5. Scoped implementation fulfilment

1. Written scope from the call (bullet outcomes, not tech theatre).
2. Milestone list with “done means…”
3. Build / connect / test.
4. Handover doc the customer can run without Ross on WhatsApp.
5. Optional retainer only if recurring value is clear.

## 6. Founder involvement dial

| Stage | Ross | CoS / Client Delivery |
|---|---|---|
| First 1–2 customers | Price + strategy call | Everything else prepared |
| Playbook proven | Price only when non-standard | Kickoff + delivery + follow-up |
| Recurring | Exceptions / Level 4 only | Retention, renewals, delivery |

## 7. Retention / recurring

- After delivery: 14-day check-in (outcome, not upsell spam).
- Offer retainer only where the system needs ongoing care.
- Log wins for case studies (permission first).
